# Профессиональное направление

## Кто я

Backend-инженер, ориентированный на жизненный цикл системы целиком: требования → модель предметной области → API и данные → тестирование → поставка → эксплуатация.

Мой основной коммерческий фундамент — **PHP/Laravel**, интеграции, e-commerce, CRM и большие объёмы данных. Дополняю его практикой **Go**, инфраструктурой и архитектурными задачами. Есть опыт координации backend-разработки и технического развития коллег.

## Какие задачи интересны

- Сложный backend с содержательной бизнес-логикой.
- Микросервисы, интеграции, event-driven системы.
- Data-intensive системы, каталоги, поиск и аналитика.
- ERP и автоматизация производственных процессов.
- Надёжность, производительность, качество и инженерная платформа.
- Роли с возможностью влиять на архитектуру и процесс разработки.

## Целевые роли

**Senior Backend Developer (PHP/Laravel), Senior PHP Developer, Backend PHP + Go, Senior Fullstack** — при существенной backend-составляющей. Возможен технический lead с участием в разработке.

## Формат

Полная занятость; предпочтительно удалённо или гибридно. Офис и переезд — по договорённости. Открыт к продуктовым командам, e-commerce, B2B, ERP/production-tech и SaaS.

## Что могу привнести команде

Опыт развития legacy без остановки бизнеса, работы с качеством данных, API и интеграциями, внедрения CI/CD, проектирования сервисов и повышения предсказуемости production.
