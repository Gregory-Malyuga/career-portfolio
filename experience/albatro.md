# Альбатро — e-commerce, маркетплейсы и автоматизация

**Июнь 2022 — февраль 2023 · PHP + Python Developer**

## Контекст

CRM, товарные каталоги, каналы продаж и обмен данными между интернет-магазином и маркетплейсами.

## Что делал

- Интеграции с **Ozon, Wildberries и Яндекс Маркетом**: заказы, остатки, цены.
- Синхронизация **50 000 товарных позиций** с обновлением каждые **15 минут**.
- Python-сервисы для сбора и очистки данных из внешних источников.
- Автоматическая классификация товаров с **Pandas/NumPy**: нормализация названий и определение категорий.
- Развитие существующего CRM-монолита, REST-интеграции, устранение ошибок.
- Автоматизация ручной работы — более **10 часов в неделю** по резюме.
- Docker и GitLab CI/CD; сокращение развёртывания с нескольких часов до **20 минут**.
- Локальная среда разработки через Bash/Makefile.

## Основные инженерные задачи

Идемпотентная обработка обновлений, разные форматы данных поставщиков, согласованность остатков и цен, устойчивость к временной недоступности внешних API.

## Стек

PHP 7.4, Laravel 8, Python, Flask, Pandas, NumPy, aiohttp, asyncio, MySQL, Redis, RabbitMQ, Docker, Nginx, Linux, GitLab CI/CD.
