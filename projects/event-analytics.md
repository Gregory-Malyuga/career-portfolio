# Event Analytics — Kafka + ClickHouse

**Тип:** коммерческий кейс · **Компания:** Европейская Юридическая Служба

## Задача

Аналитические отчёты по событиям и операциям CRM должны быстро формироваться при растущем потоке данных.

## Решение

- Kafka для доставки событий.
- ClickHouse для аналитических запросов и агрегаций.
- Разделение операционной нагрузки и аналитического чтения.
- Метрики, логирование и алертинг для контроля обработки.

## Результат по исходному CV

- **Более 10 млн событий в день**.
- Снижение длительности построения отчётов **с более чем 30 секунд до менее 1 секунды**.

## Темы для технического интервью

Партиционирование Kafka, балансировка consumer group, повторная обработка, дубликаты, идемпотентность, backpressure, модель данных ClickHouse и контроль задержек.

Значения производительности приведены из резюме; детали внутренней схемы и конфиденциальные данные не публикуются.
